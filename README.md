# Student Performance Predictor

## Internship
Sqrock IT Solutions – Data Science Internship

## Project Overview
This project analyzes student performance using Microsoft Excel. The objective is to understand how study hours, attendance, previous scores, and assignment scores affect final marks.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Column Chart
- Bar Chart
- Line Chart

## Dataset
Student Performance Dataset

## Analysis
- Study Hours Analysis
- Attendance Analysis
- Previous Score Analysis
- Assignment Score Analysis

## Key Insights
- Higher study hours improve performance.
- Better attendance increases marks.
- Previous scores influence final results.
- Assignment performance is positively related to final marks.

## Recommendations
- Encourage regular study habits.
- Improve student attendance.
- Conduct frequent assignments.
- Support low-performing students.

## Conclusion
Microsoft Excel was used to analyze student performance and create an interactive dashboard that helps identify the key factors affecting academic results.
